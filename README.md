# miniature_store
Author- Aman Raj
<br>
this is an e-commerce website of an online e-bookstore.
<br>
The project integrates secure payment processing through Razorpay, ensuring that transactions are safe and reliable. It is to be implemented using PHP, MySQL, HTML, CSS, JavaScript, and Tailwind CSS, following a robust client–server architecture.
<br>
database has been included- miniature_store.sql file.
<br>
all source code have been included.
<br>
install Xampp and start server and mysql. 
<br>
then type "localhost/" on any web browser. 
<br>
A dashboard will open, then click on phpmyadmin and create new database. 
<br>
name this database "miniature_store" and press enter. 
<br>
now, click on import and import the miniature_store.sql file included in this folder.
<br>
press enter and now you are done...type "localhost/miniature_store/ " on browser's tab and hit enter. website will open.
